# Histórico de versões

## 1.0.0 — 26/10/2026 | Pacote para GitHub

- Organizado o repositório público a partir do **PBIP fornecido pelo autor**, preservando a versão escolhida para o portfólio.
- Excluídos arquivos de cache, configurações locais e outros conteúdos desnecessários no GitHub.
- README reescrito com perguntas de negócio, indicadores, instruções de reprodução e limitações.
- Mantidos gerador Python, dataset sintético, scripts SQL, modelo dimensional e testes automatizados.
- Referência visual e prévia analítica identificadas como ilustrações, não como screenshots reais do Power BI.
